# 《美式城市街景》制作工程说明

可交互的美式市中心沙盘：Three.js（npm，0.181.2）+ esbuild（0.25.12）打包成单文件 HTML。几何、贴图、车辆、建筑全部由程序生成，成品不依赖外部素材和网络。场景设计见项目 `2 内容与分镜/场景设计.md`。

## 成品与操作

- 成品：`4 输出成品/HTML/美式城市街景.html`（约 0.7 MB），双击即可用浏览器打开。
- 拖拽旋转、滚轮缩放（朝鼠标位置缩放）、右键或双指拖动平移。
- 底部按钮：白天／黄昏／夜晚；五个预设视角；跟随公交；自动旋转；全屏。
- 点击任意车辆或轻轨列车可跟随；`Esc` 或「退出」停止跟随。跟随时如被楼体挡住，镜头会自动绕到看得见的角度。
- 键盘：`1` `2` `3` 切换时段，`H` 隐藏界面。
- 帧率偏低时会自动降低渲染分辨率，再不够则关闭环境光遮蔽。

## 命令

```bash
npm install                 # 首次
node build.mjs              # 正式构建（压缩）
node build.mjs --dev        # 开发构建（不压缩，报错可读）
node shot.mjs --shots all:0,ix:0,canyon:1,river:2 --warp 45
node shot.mjs --shots none --bench        # 只测每帧耗时
node uitest.mjs             # 交互测试，截图在 build/ui/
```

- `shot.mjs` 的一张图写作「视角:时段」。视角是预设名（`all` `ix` `canyon` `main` `river`）或用 `--cam 名字=tx,ty,tz,方位角,仰角,距离` 自定义；时段 0 白天、1 黄昏、2 夜晚。`--warp 秒数` 先把仿真快进再拍。
- 工作区 `.claude/launch.json` 里写了 `streetscape` 配置（8813 端口静态服务器，指向成品目录），尚未实际启动验证。

## 关键做法

- **车道图**：每条街按方向和车道拆成路段车道，路口用贝塞尔曲线连接直行、右转、左转。只有单行道允许左转，双向道只直行和右转，因此两相位信号灯下同一相位内没有冲突车流。车辆不变道。
- **跟驰**：智能驾驶员模型（IDM）。红灯、公交站、前方无空位都按「前方有一辆静止的车」处理；绿灯起步前检查路口内是否还有横向车辆、出口是否有空位，避免堵死路口。
- **高架**：8 条车道路径各自从地块一边开到另一边。匝道用「增减车道」方式接入主线，没有合流冲突，所以高架车流不需要让行逻辑。
- **地块边缘**：车道向外延伸 36 米，车辆在界外生成和消失，用裁剪平面在地块边缘切齐。
- **立面**：不用贴图。每面墙带「开间宽、层高、样式、随机种子」等顶点属性，窗格在片元着色器里计算并做了抗锯齿，夜间按格随机亮灯。
- **昼夜**：一个 0—2 的参数在白天、黄昏、夜晚三组光照之间插值；环境反射贴图随之重新生成。
- **阴影**：单张 4096 阴影图，范围随相机距离伸缩并对齐到阴影像素，拉近时更清晰。

## 已验证

环境：Apple M5 Pro、macOS、Chrome 157、Node 24.14.1，无头 Chrome 走 Metal。

- 截图检查了五个预设视角的白天、黄昏、夜晚，以及路口、立交分合流、轻轨弯道、掉头环岛、桁架桥、观景塔广场等近景；控制台无报错。
- 交互测试 17 项全部通过：滚轮缩放、拖拽旋转、右键平移、三个时段按钮、预设视角、跟随公交（连续 24 秒目标不脱离、视线不被遮挡）、点击车辆跟随、`Esc`、`H`。
- 车流稳定性：把仿真快进到 1826 秒和 5426 秒，车辆总数保持在 750—800 辆，约三成在等红灯，没有卡在路口里的车。
- 性能：1440×900 下 60 帧（无头模式上限）；纯渲染耗时在 2560×1440 下为每帧 1—8 毫秒。城市搭建约 0.4 秒。
- 场景规模：81 栋建筑、1145 棵树、约 700—800 辆行驶车辆、949 辆停放车辆、647 个行人、577 条车道（含路口连接）。

## 没验证的和已知限制

- 没有在真实屏幕上人工操作验收，交互结论来自无头 Chrome 的模拟输入。
- 没在高分屏（设备像素比 2）上实测帧率；无头模式下窗口设为 1800×1800 和 2560×1440 时截图会卡住（1600×1000、1440×900 正常），原因未查明；同样是 2560×1440，跳过截图只测渲染则正常。
- 只在本机 Chrome 上跑过，Safari、Firefox 和其他机器未测。
- 车辆不变道；公交只在主街专用道和码头环岛停靠；高架与地面之间没有匝道。
- 行人只沿街区人行道绕圈，不过马路。
- 立交分合流处的桥面是几条带子叠放出来的，贴近看有细缝。
- 夜间路面照明是贴在地面的光斑，不是真实光源，楼体不会被路灯照亮。
