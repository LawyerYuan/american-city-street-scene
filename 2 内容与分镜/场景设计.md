# 《美式城市街景》场景设计

2026-11-13 建档。用途：用户自己看着玩，不是视频素材，也不对外发布。

## 用户要什么

用户原话：参考一张城市俯瞰截图，「用 three.js 做一个美式风格的 3D 街景，可以缩放、有车流流动」；补充说明是「我自己看，就那种长宽都是 1:1 的场景，我喜欢看高架、公交、车流、高楼林立的这种感觉」。

用户确认过的方案（2026-11-12，聊天中确认，回复「没问题，开工」）：

- 一块约 700 米见方的美式市中心沙盘，四边切齐，画面铺满窗口。「1:1」按地块为正方形理解。
- 高架主线穿城，带一座含环形匝道的多层立交；楼间另有芝加哥式高架轻轨。
- 方格路网，红绿灯路口；林荫大道带红色公交专用道，公交按线路跑、到站停靠。
- 摩天楼群、退台式老楼、带屋顶水塔的砖楼、停车楼；保留参考图里的水面、摩天轮、观景塔。
- 白天、黄昏、夜晚可切换；滚轮缩放、拖拽旋转、右键平移；点车辆可跟车。
- 交付为双击就能打开的单文件网页，不联网、不做声音。
- 布局原创，不照搬截图，不用游戏素材；质感是干净的微缩模型，不追求游戏级写实贴图。

## 实际布局

坐标：x 向东、z 向南，地块为 [-360, 360] 见方，单位米。

| 区域 | 内容 |
|---|---|
| 西侧 | 一条南北向的河（宽约 116 米）。5 座街道桥跨河，南端一座为钢桁架桥；桥头有小桥楼；河上有游船、驳船和水上出租 |
| 河岸 | 滨河绿地与步道；主街尽头是伸入河中的木栈桥码头，上有摩天轮、旋转木马和小摊，码头前是公交掉头环岛 |
| 中部与东北 | 摩天楼群，最高一栋楼体 318 米（含天线约 390 米），另有 268 米退台石楼、252 米斜顶玻璃塔、236 米黑色板楼等 |
| 主街（东西向，z = -60） | 双向林荫大道，中央绿化带，两侧红色公交专用道和候车亭 |
| 高架主线（东西向，z = 180） | 双向 6 车道，架在 Elm St 上方，西端跨河出界 |
| 高架北支（南北向，x = 60） | 双向 4 车道，从楼群峡谷中穿过，南端接喇叭形立交：跨线桥 + 270° 环形匝道 + 外侧半定向匝道 + 两条右转匝道 |
| 高架轻轨 | 沿 2nd Ave 南下，在路口上方急弯向西，与街道桥叠成双层桥跨河；主街路口上方设「MAIN ST STATION」站 |
| 西南 | 观景塔广场（塔高约 190 米）、砖砌仓库、内环草地 |
| 东南与南缘 | 大卖场与停车场、加油站、餐车式快餐店、汽车旅馆、教堂、低层商铺 |

路网为 5 条南北向街道 × 6 条东西向街道，30 个信号灯路口。单行道与双向道混用，路面有黄色双实线、白色车道线、斑马线和停车线。

## 会动的东西

- 车流：轿车、SUV、皮卡、厢式车、黄色出租车、货车、半挂卡车、校车。地面车辆在路口按红绿灯排队、起步、转弯；高架车辆全程不停，经匝道分流合流。
- 公交三条线：14 路（码头线，沿主街往返，在码头环岛掉头）、22 路（市中心环线，顺时针绕圈，不出界）、9 路（高架下大道，南北直行）。14 路部分为铰接车。
- 高架轻轨四节编组，双向对开，进站停靠。
- 摩天轮缓慢转动，轿厢保持水平；河上船只往返；人行道上有行人。

## 以下是制作者的取舍，用户没有逐项确认

- 把参考图的「海湾」改成贯穿西侧的一条河，以便放街道桥、桁架桥和双层桥。
- 加了高架轻轨、行人、船只、广告牌（内容全部虚构）、美国国旗。
- 默认视角从东南偏南俯瞰；白天太阳在东南，黄昏转到西边。
- 公交只在有专用道的主街和码头环岛停靠。22 路在其他街道、9 路全程不停站，避免公交占道引起路网堵死（车辆不会变道）。
- 高架与地面路网之间没有上下匝道，高架车流只在地块边缘进出。
- 广告牌中有一块律师广告（「INJURED? Call 555-0199 · Baxter Law」），属虚构玩笑。

## 没做的

声音；行人过马路；车辆变道与超车；真实城市或真实品牌的复刻。
