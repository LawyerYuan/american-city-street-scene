# 美式城市街景

一个程序生成的美式市中心 Three.js 可交互沙盘，打包为单文件 HTML，打开即玩，无需安装。

**在线访问：** https://lawyeryuan.github.io/american-city-street-scene/

## 场景

约 700 米见方的美式市中心：西侧一条河与 5 座街道桥、摩天楼群、东西向高架主线与南北支线、喇叭形立交、高架轻轨、红色公交专用道、码头摩天轮、观景塔。地面车流按红绿灯排队通行，公交三条线，白天／黄昏／夜晚可切换，可缩放旋转并点车跟随。

全部几何、贴图、车辆、建筑均由程序生成，不依赖任何外部素材，运行时不联网。

场景规模：81 栋建筑、1,145 棵树、约 700—800 辆行驶车辆、949 辆停放车辆、647 个行人、577 条车道（含路口连接）。

## 操作

- 拖拽旋转、滚轮缩放（朝鼠标位置缩放）、右键或双指拖动平移。
- 底部按钮：白天／黄昏／夜晚；五个预设视角；跟随公交；自动旋转；全屏。
- 点击任意车辆或轻轨列车可跟随；`Esc` 或「退出」停止跟随。
- 键盘：`1` `2` `3` 切换时段，`H` 隐藏界面。
- 帧率偏低时会自动降低渲染分辨率，再不够则关闭环境光遮蔽。

## 目录

```text
index.html                # 成品（与 4 输出成品/HTML/ 内文件相同）
2 内容与分镜/场景设计.md    # 场景设计说明
3 制作工程/街景/            # 源码与构建脚本
4 输出成品/HTML/           # 成品单文件
4 输出成品/静帧/           # 五个预设视角截图
```

## 构建

```bash
cd "3 制作工程/街景"
npm install
node build.mjs              # 正式构建（压缩），输出到 4 输出成品/HTML/
node build.mjs --dev        # 开发构建
node shot.mjs --shots none --bench   # 性能测试
node uitest.mjs             # 交互测试
```

## 说明

- 本场景为纯虚构的机制演示，不对应任何真实城市或地点。
- 车辆不变道；公交只在主街专用道和码头环岛停靠；高架与地面之间没有匝道。
- 开发与验证在 Chrome 上完成，Safari、Firefox 与高分屏未实测。
- 使用 [Three.js](https://threejs.org/)（MIT License）。
